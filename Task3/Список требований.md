# Список требований к безопасности

## Требования к безопасности

1. Данные между клиентом, сервером и внешними зависимостями передаются в зашифрованном виде
2. Доступ к устройствам и данным получают только авторизованные на это пользователи и системы
3. Внешние системы получают минимально необходимый набор данных для выполнения работы
4. Доступ к сети партнеров осуществляется через VPN
5. Доступ к сети предприятия от партнеров регулируется белым списком адресов
6. Для аутентификации и авторизации клиента используются защищенные куки
7. Конфиденциальные данные перед передачей во внешние системы обезличиваются или заменяются на идентификаторы, например UUID
8. Сети предприятия защищены от DDoS-атак на уровне точки входа
9. Используется шифрование персональных данных в базах данных и при передаче
10. Используется валидация на сложность при установке пароля
11. Используется многофакторная аутентификация
12. Используется принцип наименьших привилегий (Least Privilege) для операторов сопровождения


## Протоколы аутентификации и авторизации

- OpenID Connect (OIDC) для аутентификации клиента
- OAuth 2.0 для аутентификации при API взаимодействиях с ограниченным временем жизни токена
- MFA при первом входе на новом устройстве
- Для операторов поддержки используется role-based access control (RBAC) с применением принципов наименьших привилегий

## Взаимодействие между системами предприятия и внешней платформой

### Открытие шлагбаума/двери подъезда с помощью видиеоидентификации

- С помощью камер видеонаблюдения происходит идентификация пользователя (биометрия/госномер)
- Происходит проверка на наличие доступа к определенному устройству, заранее зарегистрированное в мобильном приложении и подтвержденное оператором
- При наличии доступа система проходит аутентификацию с помощью OAuth 2.0 в системах партнеров
- Отправляется запрос с токеном во внешнюю систему, перед отправкой запрос шифруется на уровне контура предприятия, например с помощью IpSec
- Запрос не содержит конфиденциальной информацией, клиент и устройство передаются в виде идентификаторов
- Внешняя система расшифровывает запрос и проверяет права на выполнение действия или получение информации
